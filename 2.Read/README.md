# 📖 2.Read — 读书 · 观影

整个「输入消化」区。读书、看电影 / 剧集的笔记都在这里，靠 frontmatter 字段 + Dataview 自动汇总成书架、观影库。

**子目录**
- `books/` —— 书籍笔记（封面图放 `books/assets/`）
- `media-DB/movie`、`media-DB/series` —— 用 Media DB 插件抓取的影视条目
- `douban/` —— 豆瓣插件抓取的条目（book / movie / teleplay）

**两个入口页**
- [[bases图书馆.base]] —— 用 Bases 展示的书库:在读 / 已读 / 待读 / 未读完 / 概览 / 年度书单 / 全部藏书,卡片上字段可直接改
- [[bases影视库.base]] —— 用 Bases 展示的片库:在看 / 待看 / 已看 / 弃剧 / 片单 / 口味对照(我的评分 − 豆瓣分)/ 按年代
- [[书架]] / [[观影库]] —— 旧的 Dataview 版总览(好看但容易卡,保留作参考)

注:Bases 卡片视图依赖自研插件 Editable Cards(`editable-cards`,已内置),要先在「第三方插件」里启用。书的分类看 `阅读状态`(未开始 / 正在阅读 / 已读完 / 未读完),只翻了个大概的书在 `阅读方式` 填 `概览` 就会进「概览」视图;影视看 `state`(待看 / 正在观看 / 已看 / 弃剧)

**新建方式**
- 装 Book Search / Media DB / 豆瓣 插件后，命令面板搜索书籍/电影名称自动抓取（模板已对接字段）。
